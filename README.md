# التطبيق الإسلامي (الاسم مؤقت) — الإصدار 1.0 (المرحلة الأولى)

تطبيق Android مبني بـ Flutter، يعمل **بدون إنترنت**، بدون حساب، بدون إعلانات، بدون تتبع.

## المنفَّذ فعليًا في هذه المرحلة
- القرآن الكريم كاملًا (١١٤ سورة، ٦٢٣٦ آية) بالرسم العثماني وخط Amiri Quran.
- فهرس السور، وفتح أي سورة، وزر «السورة التالية».
- البحث في أسماء السور ونص الآيات (بدون حساسية للتشكيل).
- حفظ آخر موضع قراءة تلقائيًا + زر «متابعة القراءة» في الرئيسية.
- علامات مرجعية (حفظ/حذف/فتح).
- نسخ الآية ومشاركتها (مع اسم السورة ورقم الآية).
- تغيير حجم الخط (معاينة حية)، والوضع الفاتح/الليلي/التلقائي، واتجاه RTL.
- صفحة الإعدادات: الخصوصية والمصادر والتراخيص.

## غير منفَّذ بعد (مؤجل عن قصد)
الأذكار، مواقيت الصلاة، التنبيهات، القبلة، السبحة، الأعمال اليومية، التلاوات الصوتية، التفسير، الأحاديث، قسم الأطفال، التنقل بالجزء/الصفحة.
> لا توجد أزرار شكلية: الأقسام غير المنفذة غير ظاهرة في التطبيق أصلًا.

## كيف تبني ملف APK بدون تثبيت أي برنامج برمجة
1. اعمل حسابًا مجانيًا على **github.com** (زر Sign up).
2. اضغط علامة **+** أعلى الصفحة ثم **New repository**. اكتب اسمًا (مثلًا `islamic-app`)، اختر **Private**، ثم **Create repository**.
3. فك ضغط ملف ZIP على الكمبيوتر. ادخل المجلد، ثم اضغط **uploading an existing file** في صفحة المستودع، واسحب **محتويات** المجلد (وليس المجلد نفسه) إلى الصفحة، وانتظر انتهاء الرفع، ثم اضغط **Commit changes**.
4. **تأكد من وجود مجلد `.github`**: لو لم يظهر في المستودع (بعض المتصفحات تتجاهل المجلدات التي تبدأ بنقطة): اضغط **Add file ← Create new file**، واكتب في خانة الاسم بالضبط `.github/workflows/build.yml` (الشرطة المائلة تُنشئ المجلدات تلقائيًا)، وافتح الملف `build.yml` من الـ ZIP والصق محتواه، ثم **Commit changes**.
5. ادخل تبويب **Actions**: سيبدأ البناء تلقائيًا (دائرة صفراء تدور). انتظر حوالي ١٠–١٥ دقيقة حتى تظهر علامة ✓ خضراء.
6. اضغط على اسم التشغيل، انزل لأسفل الصفحة إلى **Artifacts**، وحمّل **app-release-apk**. فك ضغطه تجد `app-release.apk`.
7. انقله لهاتفك وافتحه (قد يطلب السماح بالتثبيت من مصدر غير معروف).

**لو ظهرت علامة ✗ حمراء:** افتح التشغيل الفاشل، اضغط على الخطوة الحمراء، وانسخ رسالة الخطأ كما هي وابعتها لي.

## مصادر المحتوى والتراخيص
| المكوّن | المصدر | الترخيص |
|---|---|---|
| نص القرآن | مشروع quran-json (risan) ← موسوعة القرآن الكريم quranenc.com | CC BY-SA 4.0 (نص الترخيص في `assets/licenses`) |
| خط القرآن | Amiri Quran | SIL OFL 1.1 |
| المكتبات | flutter_riverpod, shared_preferences, share_plus, scrollable_positioned_list | تراخيصها مفتوحة (تظهر داخل التطبيق من الإعدادات) |

## أدوات التحقق
- `python3 tool/verify_quran_data.py`: يتحقق من ١١٤ سورة و٦٢٣٦ آية وترقيم كل آية وبصمة SHA-256 للملف.
- الاستثناء الوحيد المسجَّل: مسافة رفيعة (U+2009) داخل كلمة في البقرة ٢:٧٢ موجودة في المصدر الأصلي ولم نعدّلها.

## هيكل المشروع
```
lib/core/       الثيم والثوابت وأدوات النص العربي
lib/data/       نماذج القرآن + البحث + الإعدادات + العلامات (providers)
lib/features/   home / quran / settings
assets/         نص القرآن والخط والتراخيص
test/           اختبارات الوحدات واختبار تشغيل أساسي
tool/           أدوات بناء والتحقق من بيانات القرآن
```
